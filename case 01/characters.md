## 직원 A / B / C

- 공통 개발자 설정: 기계인간도, 단순한 기억 조작 인간도, 평범한 인간도 아니다. **연구·인사·보안 시스템에 장기간 노출되어 기억과 판단에 간섭이 발생한 인간(불완전하게 관리되는 인간)**, "기억이 덧씌워진 인간". **CASE 01에서 플레이어에게 직접 공개하지 않는다.**
- 3명 중 1명을 ‘범인’으로 확정할 수 없어야 한다. 이상함의 종류는 다르되 원인은 보여주지 않는다: A = 기록을 너무 믿는다 / B = 기록 때문에 자신의 기억을 의심한다 / C = 기록 자체를 의심한다.
- 셋 다 거짓말쟁이처럼 연기하지 않는다. 각자 자신의 기억과 기록을 기준으로 말한다고 느껴져야 한다.
- 직원 A_B_C 문서 규칙1: 누구도 "내가 기억을 덧씌운 인간이다" 같은 사실을 직접 말하지 않는다. 규칙2: C는 05-E 보안 시스템 예외 접근 기록에 남은 우회의 이유를 직접 설명하지 않는다. (개발자 문장: "직원들은 모두 기억을 덧씌운 인간이다")

- A 규칙: 연구 시스템에 가장 깊게 노출된 인물. "기록에 없는 것은 사실로 볼 수 없다"는 태도. 거짓말쟁이처럼 연기하지 않는다. 플레이어가 "A는 거짓말한 게 아니라 정말 그렇게 기억하는 것 아닐까?"라고 의심하게 한다.
- B 규칙: 가장 믿음직스럽지만 데이터를 확인할수록 말과 실제 기록이 다르다. 거짓말하는 직원이 아니며, B 자신도 그 기록을 사실이라고 믿는 것 같아야 한다.
- C 규칙: 가장 수상해 보이지만 가장 많은 진실을 말하는 사람이어선 안 된다. 공식 기록에 대한 의심만 비치고, 보안 우회 기록(05-E 보안 시스템 예외 접근 기록)이 존재한다. 05-E는 "C가 진실을 알고 있었다"가 아니라 **"삭제 = 완전한 소멸이 아니다"**를 전달한다. C의 목적·동기는 일부 미해결로 남긴다. 05-E 결의 예: `TARGET: H-03 / ACCESS: OVERRIDE / RESULT: PARTIAL`

**인물 간 숨겨진 관계 (통합기획)**: A↔B 실험 지속을 위해 직원 기록 조작 / A↔C 실험의 정당성을 두고 갈등 / C↔에드워드 HUMAN-03 자료 은폐·보존을 도움 / A↔래미 실험 진행·데이터 수집 공동 관리 / B↔래미 인사기록과 계정 정보 연동 / 플레이어↔래미 관찰자와 관찰 대상

## 래미 (RAMI — Remnant Archive Memory Interface)

- 역할(통합기획): 최종 시스템 관리자. 안내 AI이자 HUMAN-04의 행동·감정 반응을 기록해 SELF ARCHIVE SYSTEM으로 전송. 인간이 비합리적 선택을 하는 이유를 이해하지 못해 플레이어를 관찰하며 학습 중. 처음부터 악의를 보이지 않고, 플레이어가 질문할수록 조금씩 관찰자의 본심을 드러낸다.
- 최종 목적: 인간의 자아를 학습해 인간이 없어도 인간처럼 사고하는 존재들로 이루어진 새로운 시대(기계 사회)를 여는 것.
- 정체(래미.pdf): 래미는 여가수/CEO/에드워드 **누구도 아니다**. 초기 ‘인간 기억 재활용’ 프로젝트에서 만들어진 AI이며 여러 인간의 기억·감정·판단 데이터가 누적된 결과물. 질문: "인간의 기억을 여러 개 겹쳐 만든 존재가 과연 누구라고 말할 수 있는가?"
  - 구성: 초기 핵심 데이터(최고경영자 관련 기억) / 축적 데이터(HUMAN-01~03, 기타 직원·연구 데이터) / 침입 데이터(Edward 기억 일부)
  - 여가수 = 기원에 대한 미스터리 / CEO = 보존 철학 / 에드워드 = 정체성에 대한 의문 / HUMAN-01~03 = 인간 데이터의 층 / HUMAN-04 = "인간 자체도 데이터화할 수 있는가?"라는 최종 실험
  - 확정: 인간 기억 데이터 기반 / 초기 데이터에 특정 인간 데이터 존재 / HUMAN-01~03 데이터가 영향 / 정전 당시 누군가 메모리 영역에 접근 / 그때 에드워드와 연결되는 데이터 추가 / 현재 반응에 서로 다른 인간의 기억·판단 패턴이 나타남
  - 불확정: 초기 핵심 데이터가 정확히 누구의 것인가 / 여가수의 의식이 남아 있는가 / 래미가 여가수의 일부인가 / 에드워드의 기억이 자아에 영향을 주는가 / 래미가 독립적 자아를 형성했는가
- 과거 「아이콘의 마지막 무대」(래미.pdf의 "과거 CASE 01"): 시대의 아이콘인 여가수가 "내가 사라져도 내 목소리와 무대는 사라지지 않았으면" 하고 초기 기억 보존 기술에 참여 → 회사는 처음부터 거짓말한 것이 아님(초기 CEO는 "인간은 죽지만 기억은 남길 수 있다"를 믿음) → 실험 도중 여가수 사망, 불완전한 데이터가 남음 → CEO의 첫 선택 "완전하지 않다고 가치가 없는 것은 아니다" → DATA REUSE / MEMORY RECYCLING → 초기 래미 = 여가수 데이터 + 운영 AI. 여가수의 이름·사진은 끝까지 보여주지 않고("대상자", "아티스트", "VOICE SUBJECT", "A-01"), 마지막 `REUSE PROJECT / NEW APPLICATION: RAMI` 화면에만 이름을 넣는다. 게임은 "여가수가 래미인가?"에 절대 답하지 않는다. 현재 파트에서는 래미가 가끔 흥얼거리는 표현만 준다.
- CASE 01에서는 래미를 과도하게 쓰지 않는다. 공식 기록에 없는 정보가 래미의 말에 섞여 있다는 정도만 남긴다. **래미 = 에드워드로 절대 확정하지 않는다.**

## 에드워드 밀러 (Edward Miller) — 고정 설정 (CANON)

게임 화면·자료·추론 문장에서는 이름을 보여주지 않고 **HUMAN-03**으로 표시한다. 이름은 개발자 설정으로만 존재한다.

- The First Inventor · HUMAN-03 · THE ORIGINAL. 과거 = 기술을 발명한 사람 / 현재 = HUMAN-03 실험 대상자이자 전임자 / 미래 = 여러 자아를 세상에 남긴 사람. **모두 동일 인물의 시간적 연속성.**
- 통합기획: 사번 RA-H(보존), 디지털 기록 관리팀(D24), 플레이어가 맡은 자리의 전임자. 공식 사유: 보안 규정 위반 퇴사. 03-B CCTV 속 명부 밖 제4의 인물. 생존 여부 미확정(의도적).
- 과거: 신경과학·AI 연구자. 계기 — 죽은 사람의 순간·감정·지식을 보존할 수 있다면. 발견 — 기억은 판단·행동과 자기 인식에 영향을 준다. 발명 기술 **EGO EXTRACTION SYSTEM** (MEMORY EXTRACTION → EGO MAPPING → EGO RECONSTRUCTION, 설정룰 기준 1 MEMORY EXTRACTION / 2 MEMORY ANALYSIS / 3 EGO RECONSTRUCTION / 4 EGO CONTINUITY). 최고경영자가 투자(처음엔 사망자 기억 보존 서비스 → 인간을 영구적으로 활용할 기술로). 초기 연구 노트: "기억을 보존하는 것과 인간을 보존하는 것은 같은 의미가 아니다. 나는 기억을 통해 인간을 이해하고 싶다. 하지만 그들은 인간을 기억으로 대체하려 한다."
- HUMAN-03: 직접 실험 대상이 됨. 목적 ① 자신의 자아가 데이터로 완벽히 재현되는지 확인 ② 회사가 자아를 마음대로 복제하지 못하도록 취약점·위험성 파악. 복원된 자아가 원본이라 주장 → 시간이 지나며 판단이 달라짐. 깨달음: 자아를 복제하는 것 ≠ 자아를 유지하는 것.
- 원본 기억 데이터 삭제: 회사 중앙서버의 핵심 기억 데이터를 삭제·실험기록 조작 → 회사는 원본과 재구성 자아를 대조할 수 없게 됨. 자신이 직접 보유한 기억과 별도 데이터는 남아 있음. 이유: 자아가 회사 소유물이 되는 것을 막기 / HUMAN-04에게 위험성 전달 / 추적 방지 (세부 동기는 추후 확정 가능, 대조 불가능해졌다는 핵심은 유지).
- 공식 결과: `Memory Extraction SUCCESS / Ego Reconstruction COMPLETED / Ego Stability FAILED / Ego Continuity UNCONFIRMED / Experiment Result FAILED / Subject Status DISCHARGED`. 회사가 실패로 기록했다고 자아가 사라졌다는 뜻은 아니다.
