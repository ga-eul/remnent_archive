# 단서 제작 에셋 정리표 — CASE 01 「신입사원」

외부 작업(ChatGPT 협업)용 정리표. 기준 문서는 `case 01/case01-logic.md` 5절(자료 목록)·6절(연결표)·9절(제한구역 조건), `case 01/disclosure.md` CASE 01, `case 01/world.md` 정답 타임라인이다. 설정이 다르면 기준 문서가 우선한다.

- **형태 칸은 제작 당시의 제안이다.** 실제 게임 표시 방식은 D54~D59로 확정했고 아래 "에셋 파일 이름 규칙" 표의 표시 방식 칸이 기준이다 (`decisions.md` 4절 7번).
- **획득장소**의 수색 단계: 1차 수색(페이지 03) / 2차 수색(05) / 3차 수색(06, 제한구역).
- **순위**: ① 진행 필수(제한구역 개방·최종 추론·정체 추리) → ② 엔딩 3 조건 자료 → ③ 선택·완성도 자료 → ④ 코드 텍스트로 대체 가능(이미지 에셋 우선도 낮음).
- 기준 날짜(오늘, 입사일) **4XXX.04.12(목)**. 사건일 **4XXX.01.24** (03:00, CCTV 16:40). 시스템 로그는 2시간마다 짝수 정시 자동 저장(04:00·18:00 등). 시각 표기는 `4XXX.04.12 09:17` 형태.
