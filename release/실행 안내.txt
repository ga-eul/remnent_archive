REMNANT ARCHIVE — CASE 01 「신입사원」 데모 (Windows)

■ 실행 방법
1. 이 zip 파일의 압축을 풉니다. (zip 안에서 바로 실행하지 말고 꼭 풀어 주세요)
2. RemnantArchiveDemo-{VERSION}-portable.exe 를 더블클릭합니다.
   설치 과정 없이 바로 실행됩니다. 처음 켤 때는 몇 초 걸릴 수 있습니다.

■ 경고 창이 뜨는 경우 (정상입니다)
개인이 만든 데모라 코드 서명이 없어서 아래 경고가 뜰 수 있습니다.
{HOST_WARNING}- 브라우저 "흔히 다운로드되지 않는 파일" → [유지] (Edge는 … 메뉴 → [유지])
- Windows "Windows의 PC 보호" → [추가 정보] → [실행]

■ 플레이 안내
- Windows PC 전용입니다.
- 이어폰 착용을 권장합니다.
- F11 키로 전체 화면을 켜고 끌 수 있습니다.
- 인터넷 연결 없이도 플레이할 수 있습니다.
- 진행 기록은 자동으로 저장되어, 껐다 켜도 이어서 할 수 있습니다.

■ 저장 위치 / 삭제
- 진행 기록: %APPDATA%\Remnant Archive Demo
- 삭제하려면 exe 파일과 위 폴더를 지우면 됩니다.
