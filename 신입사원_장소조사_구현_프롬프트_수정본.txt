3. 도면과 클릭 영역

- 장소 5곳 유지: 기록보관실 / 관제실 / 업무실험실 / 생활공간 / 제한구역
- 도면 컨테이너는 `aspect-ratio: 3 / 1`, 이미지는 컨테이너를 꽉 채우되 잘리지 않게 (object-fit: cover 금지). 클릭 영역은 같은 컨테이너 안에서 이미지 기준 % 좌표로 절대 배치해서 화면 크기가 바뀌어도 함께 움직이게 해.
- 좌표는 코드에 흩어 두지 말고 데이터 파일 한 곳(예: `data/hotspots.js`)에 `[왼쪽, 위, 너비, 높이] (%)` 형식으로 모아. 03-A 덧씌우기(`patches.box`)와 같은 형식이다.
- 빌드 없는 일반 스크립트 구조(D33)를 지켜. 새 데이터 파일은 `index.html`에 `<script>`로 순서대로 추가하고, JSON을 fetch로 불러오지 마 (파일을 더블클릭해 여는 file:// 환경에서 동작해야 함).
- 각 클릭 영역은 `<button>`으로 만들고 오브젝트 이름과 상태 표시를 붙여. 키보드 Tab 이동, Enter/Space 열기, 포커스 표시, 자료 창을 닫으면 누른 클릭 영역으로 포커스 복귀.
- 모바일: 3:1 도면은 폭 375px에서 높이가 약 125px라 직접 누르기 어렵다. 좁은 화면에서는 도면을 최소 폭(예: 720px)으로 두고 가로 스크롤을 허용하고, 도면 아래에 같은 오브젝트의 버튼 목록을 함께 보여 줘. 터치 영역은 최소 44px.
- 연출 줄이기 설정(`body.reduced`)이면 클릭 영역의 깜빡임·발광 애니메이션을 끈다.
- 기존 자료 창(showEvidence)·문서/이미지/영상 뷰어(clueView)·My Archive 재열람을 재사용해.
- 배경 이미지에 단서처럼 보이는 것이 그려져 있어도 그것만으로 획득 처리하지 마. 메인 스크린의 두뇌 그래픽, 실험 의자 등 배경 요소로 잠긴 자료를 우회 획득할 수 없게 해.
- 기존 `SPOTS`의 지점 이름(예: 03-C '책상 서랍', 06-B '명령 문서 서랍')은 새 오브젝트 이름에 맞게 고쳐. 지점 이름에 자료 결론을 넣지 마 (R-32).

6. 오브젝트 상태 표시

- 클릭한 사실과 자료를 획득한 사실을 구분해. 상태는 가능한 한 기존 `clue_*_found`와 새 하위 열람 기록에서 계산하고, 따로 저장한 표시값과 어긋나지 않게 해.
- 표시 종류:
  - 표시 없음: 아직 열람하지 않음
  - [1/2 확인]: 한 오브젝트에 하위 자료가 여러 개인데 일부만 열람 (03-C 두 수첩). 수첩 두 권이 그림에 보이므로 R-30(총량 비노출)과 충돌하지 않는다.
  - [확인함]: 그 오브젝트에서 지금 열린 자료를 모두 열람 (보조자료 오브젝트도 같음)
  - [새 자료]: 플레이어가 **이전에 한 번이라도 눌러 본 오브젝트**(잠긴 상태에서 외형만 본 경우 포함)에 그 뒤 새 내용이 열렸을 때. 읽으면 [확인함]으로 바뀐다. 예: 1차에 눌러 본 관제실 서버 랙이 2차에 열림 / 05-C 전에 눌러 본 독립 책상에 05-D가 열림 / 이미 읽은 실험 의자에 05-B-VHS 열람 후 관찰 한 줄이 추가됨. 이를 위해 오브젝트별로 "눌러 본 적 있음"과 "마지막으로 읽은 내용"을 저장한다. (이 규칙이 없으면 잠긴 상태에서 한 번 눌러 본 오브젝트에 자료가 열려도 아무 표시가 없어서, 플레이어가 다시 누르지 않는다.)
  - 나중 단계 자료를 이미 얻은 뒤 진행 단계 표시줄로 이전 단계 화면에 돌아간 경우, 그 오브젝트는 [확인함]으로 보이고 다시 열람할 수 있게 한다 (잠긴 것처럼 보이지 않게).
- '열람'은 자료 창을 연 것을 기준으로 한다. 03-B·05-B-VHS 영상을 끝까지 재생했는지는 열람·획득 조건에 넣지 마 (지금 동작과 같음).
- 보조자료를 먼저 읽어도 같은 장소의 추리 자료를 읽은 것으로 처리하지 마.
- [확인 필요] 아직 열리지 않은 자료의 오브젝트 (예: 1차의 관제실 서버 랙): 기본값으로, 눌렀을 때 외형만 짧게 관찰한 문구를 보여 주고 상태 표시와 '잠김' 표기는 하지 마. 미래 자료의 제목·설명·존재를 미리 드러내지 않으려는 것이다. 이 클릭은 열람·획득으로 기록하지 않는다.
- 03-A·03-C의 획득 시점 [확인 필요] — 기본값: 하위 부분을 **모두** 열람했을 때 `clue_03A_found`·`clue_03C_found`를 참으로 만든다. 지금은 한 번 열면 두 부분이 함께 보이므로 이렇게 해야 "면담 전에 1차 자료를 다 본 상태"가 그대로 유지된다(심문 질문은 1차 수색 정보를 근거로 함). 일부만 열람한 자료는 My Archive에 넣지 않는다.


7. 장소 완료 표시 (조사 UI 전용 — 해금·엔딩 조건으로 쓰지 마)

11.추가 구현 보완 규칙

- 이전 수색 단계로 돌아갔을 때 이미 획득한 자료의 재열람은 허용한다. 다만 재열람이 새로운 단서 획득, 단계 해금 또는 조합 결과 생성으로 이어지지 않도록 한다.
- [새 자료] 판정에 필요한 오브젝트 방문·열람 기록이 기존 세이브에 없으면 안전한 기본값을 적용한다. 기존에 획득한 자료는 [확인함] 상태를 우선 복원한다.
- 보조단서 13개는 새로운 추리 자료로 등록하지 않는다. 기존 단서 ID, 조합, 수색 진행, 엔딩 조건은 유지한다.
